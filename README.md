# 🚀 Nikhil's AI Engineer Roadmap Tracker

A personal progress tracker for the 77-day AI/ML learning roadmap (Jun–Sep 2026).

## 📦 Structure

```
├── index.html        ← Main page
├── style.css         ← All styles
└── js/
    ├── roadmap.js    ← All 77 days + 11 weeks of data
    ├── storage.js    ← localStorage helpers
    └── app.js        ← UI logic
```

## 🚀 Deploy to GitHub Pages

1. Create a new GitHub repo (e.g. `ai-roadmap-tracker`)
2. Upload all files (keep folder structure)
3. Go to **Settings → Pages**
4. Source: **Deploy from a branch** → `main` → `/ (root)`
5. Your tracker will be live at `https://yourusername.github.io/ai-roadmap-tracker`

## ✨ Features

- 📅 77-day tracker with all topics per day
- 🚀 11-week timeline view
- 🚀 Project portfolio tracker (12 projects)
- 📝 Daily notes + hours log
- 💼 Job application counter
- 🔥 Streak tracking
- 🌙 Dark / Light mode
- 📱 Mobile responsive (bottom nav bar)
- 💾 100% local — all data in localStorage, no backend needed
